# Modern E-Commerce Flutter App

A clean, responsive e-commerce shopping application built with Flutter, featuring a modern UI, reusable components, and Provider-based state management.

## Features

* Responsive modern home screen
* Product search and filtering
* Product details and ratings
* Category browsing
* Shopping cart with quantity management
* Automatic subtotal, savings, delivery, and total calculation
* Wishlist management
* Address selection during checkout
* Checkout and place-order flow
* Order history
* Order tracking
* User profile and saved addresses
* Responsive product and category grids
* Reusable product, price, rating, and order widgets
* Provider-based state management
* Clean and modular project structure
